# UI-Material

Hier werden Mockups, Screen-State-Referenzen und später geprüfte UI-Assets gesammelt.

Für jeden Screen dokumentieren: Zielauflösung, DPI, hidden/loading/empty/populated/error/disabled/focused, Eingabe/Fokus, Asset-Liste, Exportgrößen und Review-Datum.

Die fertige UI-Implementierung bleibt unter source/client-ui/ oder in der lokalen Arbeitskopie.
