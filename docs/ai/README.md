# AI-Arbeitsbereich

Dieser Ordner hält die wiederverwendbaren Arbeitsabläufe für ChatGPT/Codex. Die Prompts beschreiben Ziel, Eingaben, technische Grenzen und ein prüfbares Ausgabeformat.

- UI_WORKFLOW.md — von Screenshot und Bestandscode zu einer testbaren UI-Änderung.
- UI_PROMPT_TEMPLATE.md — Prompt für neue oder umzuschreibende Screens.
- ICON_PROMPT_TEMPLATE.md — Prompt für Icons, States und Exportvarianten.
- DEVLOG_ENTRY_TEMPLATE.md — kurzer, belastbarer Devlog-Eintrag.
- ASSET_REVIEW_CHECKLIST.md — Review vor Übernahme in die lokale Quelle.

Regel: Ein Prompt ersetzt keine technische Prüfung. Jede vorgeschlagene Änderung wird gegen die lokale UI-State-Matrix, Performance-Ziele und die vorhandenen Client-Schnittstellen geprüft.
